# CodeAlpha Hangman Game

A simple text-based Hangman game developed using Python as part of my CodeAlpha Python Programming Internship.

## Features

- Randomly selects a word from a predefined list
- Allows the player to guess one letter at a time
- Provides up to 6 incorrect attempts
- Displays the guessed letters
- Shows win and game-over messages

## Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Functions
- Strings and Lists

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run:

```bash
python hangmangame.py
